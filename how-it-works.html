Digital Resume — How It’s Built

A single-file HTML resume with semantic structure, a sticky nav, and a print media query — no framework, no build step, no JavaScript required.

Overview

The Digital Resume is a standalone HTML page hosted on GitHub Pages. It uses semantic HTML5 elements (header, main, section, nav) to organize a professional resume into scannable regions. All styling is in a single linked style.css that handles the sticky top nav, dark-navy color scheme, profile photo, section dividers, and a print media query so the page can be saved as a PDF with correct formatting. No JavaScript, no framework, no build pipeline — just two files that load in under a second.

Tech Stack

HTML CSS GitHub Pages
  • HTML5 — semantic elements (header, main, section, nav, article) make the document outline meaningful to screen readers and search engines without any JavaScript.
  • CSS3 — CSS custom properties define the color palette (dark navy, accent gold, silver text) once at :root; every component references them by variable name so a palette swap is a one-line change.
  • GitHub Pages — the resume repo is a plain GitHub repository with Pages enabled. A push to main publishes the page at https://worldtraveler247.github.io/resume/ with no build configuration.

How Each Part Works

index.html — Semantic document structure

The page is organized into top-level sections that mirror a printed resume: a header with name, clearance badge, and contact links; then sections for Summary, Experience, Projects, Education, Skills, Technical Competencies, and Contact. Each section has an id attribute that the sticky nav links to via anchor (href="#experience"), enabling smooth-scroll navigation without JavaScript.

<body>
  <nav class="navbar">
    <div class="nav-container">
      <a href="#top"       class="nav-link">Home</a>
      <a href="#summary"   class="nav-link">About</a>
      <a href="#experience" class="nav-link">Work History</a>
      <a href="#projects"  class="nav-link">Projects</a>
      <a href="#education" class="nav-link">Education</a>
      <a href="#skills"    class="nav-link">Skills</a>
    </div>
  </nav>

  <div class="container" id="top">
    <header> ... </header>
    <main>
      <section id="summary"> ... </section>
      <section id="experience"> ... </section>
      <!-- etc -->
    </main>
  </div>
</body>

style.css — Job title / date flex row

Each work experience entry uses a flex row to push the job title to the left and the date to the right — the same layout you see on a traditional printed resume. justify-content: space-between handles the spacing; align-items: baseline keeps the text on the same text baseline even when font sizes differ.

/* style.css */
.job-header {
  display: flex;
  justify-content: space-between;
  align-items: baseline;
  margin-bottom: 5px;
}

.job-header h3 {
  color: var(--white);
  font-size: 1.1rem;
}

.job-header .date {
  font-family: monospace;
  font-size: 0.85rem;
  color: var(--accent-gold);
}

style.css — Sticky nav with backdrop blur

The navbar is position: fixed at the top of the viewport. backdrop-filter: blur(10px) gives it a frosted-glass effect over the page content without needing a fully opaque background. html { scroll-behavior: smooth; } (one line of CSS) makes anchor links animate instead of jump.

style.css — CSS custom properties for theming

All colors are defined as custom properties on :root so the entire palette can be changed in one place. Components reference variables by name (color: var(--accent-gold)) rather than hardcoding hex values throughout the stylesheet.

:root {
  --primary-navy: #0a192f;
  --security-blue: #172a45;
  --accent-gold: #f4d03f;
  --text-silver: #ccd6f6;
  --text-gray: #8892b0;
  --white: #e6f1ff;
  --bg-dark: #020c1b;
  --nav-height: 60px;
}

Replicate It Yourself

  1. Create a GitHub repo named resume and enable Pages from the main branch. Your page will be live at https://<user>.github.io/resume/.
  2. Structure your HTML with semantic elements: header for identity, main wrapping all section elements, each section with an id matching a nav href.
  3. Use the flex row pattern for job entries: display: flex; justify-content: space-between; align-items: baseline; to push the title left and date right without any extra markup.
  4. Link to Google Fonts for typography. Inter is a good body font; a monospace face for dates adds a technical feel.
  5. Define all colors as CSS custom properties on :root. Use var(--accent-color) everywhere instead of hardcoding hex values — swapping the palette later takes 8 lines, not 80.
  6. Add html { scroll-behavior: smooth; } so anchor links animate. Make the nav position: fixed; backdrop-filter: blur(10px); for the frosted-glass look.
  7. Add a print media query: @media print { .navbar { display: none; } ... } so the page prints cleanly as a one-page resume. Export from your browser print dialog as PDF for the downloadable version.
